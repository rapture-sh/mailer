# Changesets

Every change users would notice carries a changeset. Add one with `pnpm changeset`, pick
patch for a fix, minor for a feature, and major for a change to one of the five type
guarantees.

Changesets opens and maintains a version PR; publishing happens in CI when that PR
merges. Nobody publishes from a laptop.

See [the changesets docs](https://github.com/changesets/changesets) for the rest.
